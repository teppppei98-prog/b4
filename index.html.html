ボーナスステージ（最終回前）
ファイナル2名が確定後、全員に+500コインを追加配布。1名に全額を賭けて、当てれば×3倍獲得。
🪙 投票の仕方（自由配分型）
各ラウンド、自分が持っているコインを3名に自由な比率で分配して投票する。
例えば 1000コインを「500 / 300 / 200」に配分してもよいし、「600 / 200 / 200」でも「333 / 333 / 334」でも自由。
※ コインを集中投資するか分散するかが戦略のカギ

※ 残存した人に賭けたコインにのみ倍率が適用される。例えば「500 / 300 / 200」で賭けて1名だけ残った場合、その1名に賭けた分だけが×3.0で返ってくる。
📖 計算例
1000コインを 水越 500 / 植田 300 / ライモン 200 で投票
→ EP1–4後、水越と植田が残存・ライモン脱落（2名残存）
→ 水越分：500 × 2.0 = 1,000コイン
→ 植田分：300 × 2.0 = 600コイン
→ ライモン分：脱落のため 0コイン
→ 合計獲得：1,600コイン（+600コインの利益）
